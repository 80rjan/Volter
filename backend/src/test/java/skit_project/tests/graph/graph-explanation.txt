4. ALL-DU-PATHS COVERAGE  за променливата `names`
------------------------------------------------------------------------
def(names)  : јазол 3        (names = new HashMap<>())

              јазол 6        (return names)           -- по јамката
(`names` никогаш не се презапишува, па секоја патека од единствената дефиниција е чиста од редефиниција — def-clear.)

du-патеки (прости def-clear патеки од дефиницијата до секоја употреба):

Забелешка: Prime Path покриеноста секогаш ја вклучува All-du-paths coverage, а понекогаш ја вклучува и Edge-Pair coverage (во случајов ја вклучува).
Prime Path покриеноста секогаш ја вклучува и Edge покриеноста, која ја вклучува Node покриеноста — па множеството {A,B,C,D} ги задоволува сите.
